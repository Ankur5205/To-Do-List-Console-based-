# To-Do-List-Console-based-
# This project is a console-based To-Do List application developed using C++.
# It allows users to add, view, and manage tasks efficiently through a menu-driven interface.
# Users can mark tasks as completed or pending for better task tracking.
# The application demonstrates object-oriented programming concepts such as classes, encapsulation, and vectors.
# This project is suitable for understanding basic task management and C++ programming fundamentals.
